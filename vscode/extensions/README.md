# Sagewood Theme

A soothing, dusty dark sage green color scheme designed for long coding sessions. 

## Features

* Easy on the eyes for late night coding
* Carefully balanced sage green accents
* Designed to reduce eye strain

## Installation

1. Open Extensions in VS Code (`Ctrl+Shift+X` or `Cmd+Shift+X`).
2. Search for **Sagewood**.
3. Click **Install**.
4. Go to **File > Preferences > Color Theme** and select **Sagewood**.
